# wisp
shell и gui оболочка os на python
## команды
whoami - имя пользователя
time - время
date - дата
datetime - дата и время
bash user -:; text - вывод текста
stop -op - выключение shell
disk - свободные и занятые gb вашего диска
clear -c - отчистка консоли
clear -h - отчистка истории команд
history - история команд
alias название=команда - ввод в алиас
aliases - все алиасы
unalias название - вывод из алиаса
unalias -all - вывод всех алиасов
run название - открытие любого файла с вашего пк
start boot -g -os -up - включение полноценной версии ос
